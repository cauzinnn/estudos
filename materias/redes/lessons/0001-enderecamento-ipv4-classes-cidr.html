Endereçamento IPv4: Classes, Sub-redes e CIDR/VLSM

Estrutura de 32 bits, classes legadas, cálculo de sub-redes ($2^h - 2$) e interfaces de rede.

1. O Modelo Mental das Classes Históricas (A, B, C, D)

No esquema de endereçamento com classes (classful, RFC 791), a fronteira entre a porção de rede (NetID) e a porção de host (HostID) era determinada rigidamente pelos bits mais significativos do primeiro octeto:

  • Classe A: Inicia com 0... (faixa 1 a 126). Máscara padrão 255.0.0.0 (/8).
  • Classe B: Inicia com 10... (faixa 128 a 191). Máscara padrão 255.255.0.0 (/16).
  • Classe C: Inicia com 110... (faixa 192 a 223). Máscara padrão 255.255.255.0 (/24).
  • Classe D: Inicia com 1110... (faixa 224 a 239). Utilizada para difusão seletiva (Multicast). Não possui divisão de hosts.

Qualquer endereço cujo primeiro octeto comece por 224 a 239 não pode ser atribuído a uma placa de rede comum de hospedeiro, servindo apenas como endereço de grupo multicast.

2. Máscara de Sub-rede e o Cálculo de Capacidade Útil

Uma máscara de sub-rede separa os 32 bits do endereço IPv4 em $n$ bits de rede e $h = 32 - n$ bits de host. O número total de combinações é $2^h$.

No entanto, dois endereços são obrigatoriamente reservados por padrão em cada bloco:

  • Endereço de Rede: Todos os $h$ bits de host iguais a 0 (identifica a sub-rede).
  • Endereço de Broadcast: Todos os $h$ bits de host iguais a 1 (envio para todos da sub-rede).

Logo, a quantidade máxima de máquinas que podem receber IP válido em uma sub-rede é sempre dada por:

$$\text{Hospedeiros Úteis} = 2^h - 2$$

3. A Regra de Ouro: Identificadores de Sub-rede Válidos

Para que um endereço represente legitimamente o identificador de uma sub-rede, todos os bits da porção de hospedeiro devem ser estritamente iguais a 0.

Considere a máscara 255.255.254.0 (/23). Ela possui $23$ bits fixos de rede e $9$ bits variáveis de host ($h = 9$).

No 3º octeto ($8$ bits), os primeiros $7$ bits são rede e o último bit é host. Portanto, no 3º octeto, apenas números pares (onde o bit menos significativo é zero, como 32, 34, 36) podem iniciar um bloco /23! Se o número for ímpar (ex: 33), o 23º bit é 1, o que viola a regra do identificador de rede.

4. Subdivisão Máxima: Enlaces Ponto a Ponto (/30)

Em topologias de roteamento, enlaces diretos conectando dois roteadores exigem apenas dois IPs úteis (um para cada interface).

A menor sub-rede útil tradicional para esse propósito é a /30 (máscara 255.255.255.252):

  • $h = 32 - 30 = 2$ bits de host.
  • Total de IPs: $2^2 = 4$.
  • IPs úteis para roteadores: $4 - 2 = 2$ máquinas.

Ao particionar um bloco maior $/A$ em sub-redes $/B$, o número de sub-redes criadas é $2^{B - A}$.

5. Parsing Real de Configuração de Roteadores (ifconfig)

Em sistemas operacionais de roteamento (como Linux em roteadores de borda), o comando ifconfig ou ip addr exibe o IP configurado e a máscara em formato decimal: 

eth0: inet addr: 146.164.5.210  Mask: 255.255.255.192

Para obter o prefixo CIDR e a sub-rede conectada:

  • 255.255.255.192 em binário possui $26$ bits 1 $\to$ prefixo /26. O passo da sub-rede é $256 - 192 = 64$.
  • As sub-redes no último octeto pulam de 64 em 64: .0, .64, .128, .192.
  • O IP .210 situa-se entre .192 e .255. Logo, a sub-rede conectada é 146.164.5.192/26.
