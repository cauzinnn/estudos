1. A Filosofia TSK: Mamdani vs. Takagi-Sugeno-Kang

No sistema clássico de Mamdani, tanto o antecedente quanto o consequente são conjuntos fuzzy linguísticos (ex: "SE pressão é alta ENTÃO válvula é muito_fechada"). Isso exige um processo custoso de truncamento geométrico e integração de área para a defuzzificação.

Em 1985, Tomohiro Takagi e Michio Sugeno introduziram o modelo TSK:

  • O antecedente continua sendo nebuloso/fuzzy (com funções de pertinência $\mu$).
  • O consequente é substituído diretamente por uma função matemática analítica das variáveis de entrada $x_1, x_2, \dots$: $$y_k = a_0 + a_1 x_1 + a_2 x_2 + \dots$$
⚡ Classes de Modelos TSK

• TSK de Ordem 0: Consequente é uma constante escalar pura: $y_k = c_k$ (ex: $y_1 = 50$, $y_2 = 120$).
• TSK de Ordem 1: Consequente é uma equação linear das entradas: $y_k = a x_1 + b x_2 + c$ (ou funções com limites como $\max, \min$).

2. Avaliação dos Consequentes Funcionais

Para cada par de entrada real $(x_1, x_2)$, cada regra da base tem seu consequente crisp $y_k$ avaliado substituindo diretamente os valores numéricos.

Regras da Prova (Exercício 5 da Lista Oficial): Entradas $\text{PESO} = 240$ e $\text{TAMANHO} = 80$:

  • $R_1: \text{ESFORÇO} = 0.7 \times \text{PESO} + 1.2 \times \text{TAMANHO} \implies 0.7(240) + 1.2(80) = 168 + 96 = \mathbf{264}$.
  • $R_2: \text{ESFORÇO} = \text{PESO} - 0.5 \times \text{TAMANHO} \implies 240 - 0.5(80) = 240 - 40 = \mathbf{200}$.
  • $R_3: \text{ESFORÇO} = \max(2 \times \text{TAMANHO}, 400) \implies \max(160, 400) = \mathbf{400}$.
  • $R_4: \text{ESFORÇO} = 0.5 \times \text{PESO} + 0.6 \times \text{TAMANHO} \implies 0.5(240) + 0.6(80) = 120 + 48 = \mathbf{168}$.
  • $R_5: \text{ESFORÇO} = \min(2 \times \text{PESO}, 400) \implies \min(480, 400) = \mathbf{400}$.

3. Grau de Disparo e Média Ponderada TSK

Cada regra $R_k$ possui um grau de certeza intrínseco ($GC_{regra}$). Seu grau de disparo final $GC_k$ é dado por:

$$GC_k = GC_{\text{antecedente}_k} \times GC_{\text{regra}_k}$$

A Defuzzificação TSK é a média ponderada de todos os consequentes pelos seus respectivos graus de disparo:

$$Y = \frac{\sum_{k=1}^{R} GC_k \times y_k}{\sum_{k=1}^{R} GC_k}$$

📊 Rastreamento Numérico Oficial (Entradas 240 e 80)

• $GC_1 = 0.0495$,   $y_1 = 264$  $\to 0.0495 \times 264 = 13.068$
• $GC_2 = 0.3230$,   $y_2 = 200$  $\to 0.323 \times 200 = 64.600$
• $GC_3 = 0.3610$,   $y_3 = 400$  $\to 0.361 \times 400 = 144.400$
• $GC_4 = 0.2025$,   $y_4 = 168$  $\to 0.2025 \times 168 = 34.020$
• $GC_5 = 0.3080$,   $y_5 = 400$  $\to 0.308 \times 400 = 123.200$
Soma Ponderada: $\sum GC_k \cdot y_k = 379.288$
Soma dos Pesos: $\sum GC_k = 1.244$
$$\text{ESFORÇO}_{\text{TSK}} = \frac{379.288}{1.244} \approx \mathbf{304.89}$$
