Módulo 1: Inferência Fuzzy Completa (Base de Prova)

Considere o sistema fuzzy com pesos de regras e variável intermediária $v_4$:

R1: Se $v_1$ é A ou B e $v_2$ é C ou D e $v_3$ não é F $\to$ prova é fácil $(0{,}82)$
R2: Se $v_1$ não é B e $v_3$ é F $\to$ prova é difícil $(0{,}92)$
R3: Se $v_2$ é C e $v_3$ é G $\to$ prova é equilibrada $(0{,}75)$
R4: Se $v_1$ é B ou $v_2$ é E $\to$ $v_4$ é X $(0{,}94)$ (Variável Intermediária)
R5: Se $v_3$ é D e $v_4$ é X $\to$ prova é difícil $(0{,}85)$
R6: Se $v_1$ é A e $v_2$ é D ou $v_4$ não é X $\to$ prova é fácil $(0{,}88)$

Tabela de Fuzzificação das Entradas:
• $v_1$: $A=0{,}65$, $B=0{,}52$
• $v_2$: $C=0{,}68$, $D=0{,}44$, $E=0{,}16$
• $v_3$: $D=0{,}14$, $E=0{,}36$, $F=0{,}80$, $G=0{,}60$

Questão 1: Ativação da Variável Intermediária (R4)

Calcule o grau de pertinência derivado para a variável intermediária $\mu_X(v_4)$ produzido pela regra R4, considerando a ponderação do peso $(0{,}94)$.

Questão 2: Avaliação com Precedência e Negação (R6)

Na regra R6 ($v_1 \text{ é } A \wedge v_2 \text{ é } D \vee \sim(v_4 \text{ é } X)$ com peso $0{,}88$), sabendo que a conjunção tem precedência sobre a disjunção:

Qual é o grau de pertinência final $\mu_{R6}(\text{fácil})$ gerado por essa regra? (Arredonde para 2 ou 4 casas decimais).

Questão 3: Agregação Mamdani para a Resposta Fuzzy

No sistema Mamdani Max-Min, quando múltiplas regras concluem o mesmo termo linguístico de saída (por exemplo, R1 e R6 concluem que a prova é "fácil"), como é calculado o grau de pertinência final agregado $\mu(\text{fácil})$?

Módulo 3: Sistemas Fuzzy Takagi-Sugeno-Kang (TSK)

Em um sistema TSK de ordem zero, a saída global é a média ponderada pelas pertinências: $$Y = \frac{\sum_{i=1}^R GR_i \cdot y_i}{\sum_{i=1}^R GR_i}$$

Questão 8: Problema Inverso TSK (Saída da Regra Desconhecida)

A saída global do sistema TSK foi $Y_{\text{final}} = 50$. Os graus de relevância ($GR$) e as saídas individuais ($y$) são:

• R1: $GR_1 = 0{,}6$, $y_1 = 30$
• R2: $GR_2 = 0{,}8$, $y_2 = 40$
• R3: $GR_3 = 0{,}5$, $y_3 = 20$
• R4: $GR_4 = 0{,}3$, $y_4 = x$

Qual é o valor exato da saída $x$ da regra R4?

Questão 9: Cálculo Direto TSK de Ordem 0

Um sistema TSK possui três regras com os seguintes parâmetros:
• R1: $GR_1 = 0{,}4$, $y_1 = 10$
• R2: $GR_2 = 0{,}6$, $y_2 = 20$
• R3: $GR_3 = 1{,}0$, $y_3 = 50$

Qual é a saída global $Y_{\text{final}}$ do sistema?

Regras e Pesos:

• $c = 0{,}80 \implies \sim c = 0{,}20$
• $d = 0{,}40 \implies \sim d = 0{,}60$
