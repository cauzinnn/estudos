1. Comparativo das Buscas Heurísticas (Informadas)

Algoritmo Função f(n) Estrutura da Fronteira Completo? Ótimo? Espaço (RAM)
Hill Climbing (Irrevogável) f(n) = h(n) (ou valor) Nenhuma (apenas estado atual) Não (para em máximos locais) Não (míope) O(1) (constante)
Busca Gulosa (Greedy Best-First) f(n) = h(n) Fila de Prioridades por h Não em árvore com ciclos Não (ignora g) O(b^m) (exponencial)
Algoritmo A* (A-Star) f(n) = g(n) + h(n) Fila de Prioridades por f Sim (se passos > 0) Sim (se admissível / consistente) O(b^d) (gargalo)
IDA* (Iterative Deepening A*) f(n) = g(n) + h(n) Pilha com backtracking e corte por f Sim (se passos > 0) Sim (se admissível) O(b × d) (linear!)

2. Teoremas Fundamentais de Heurísticas

1. Admissibilidade (Otimismo Teórico) — Obrigatória para Árvores

Uma heurística h(n) é admissível se ela nunca superestima o custo real para alcançar a meta a partir de n:
0 ≤ h(n) ≤ h*(n), ∀ n (onde h*(n) é o custo real ótimo).
Garantia: Assegura a otimalidade do A* em busca em árvore (sem conjunto de fechados).

2. Consistência / Monotonicidade — Obrigatória para Grafos

Uma heurística h(n) é consistente se satisfaz a Desigualdade Triangular para toda transição de n para n' via ação de custo c(n, a, n'):
h(n) ≤ c(n, a, n') + h(n') e h(G) = 0 para qualquer meta G.
Teorema: Toda heurística consistente é também admissível! Ela garante que os valores de f(n) nunca diminuem ao longo de uma rota (f(n') ≥ f(n)), permitindo descartar estados repetidos sem perder a otimalidade em busca em grafo.

3. Heurísticas Típicas de Prova (Exemplo: 8-Puzzle / Tabuleiro)
  • h1 (Peças Fora do Lugar): Conta quantas peças não estão na posição final. É admissível (cada peça fora do lugar precisa de pelo menos 1 movimento).
  • h2 (Distância de Manhattan): Soma das distâncias horizontais e verticais de cada peça até sua posição correta. É admissível e domina h1 (ou seja, h2(n) ≥ h1(n) para todo n).
  • Regra de Dominância: Se h2 domina h1, o A* utilizando h2 expandirá menos nós (ou no máximo igual) do que utilizando h1!

3. Regras de Ouro para a Prova

  1. Teste de Meta no A* e na UCS: Ocorre estritamente quando o nó é desenfileirado da fila de prioridades, nunca na geração!
  2. Atualização do Limite no IDA*: O novo patamar de corte é o menor valor de f entre todos os nós podados na iteração anterior. Jamais incremente somando +1!
  3. Memória: Quando a questão citar falta de memória RAM para A*, a solução padrão é o IDA* ou SMA* (Simplified Memory-Bounded A*).
