1. Modelagem com Variáveis Binárias e Técnica do Big-M

Estrutura Física / Lógica Formulação Matemática Não Linear Equivalente Linear com Big-M ($z \in \{0, 1\}$)
Custo Fixo de Ativação $$\text{Custo}(x) = \begin{cases} c x + K, & x > 0 \\ 0, & x = 0 \end{cases}$$ $$\text{Min} \; c x + K z \quad \text{s.a.} \quad x \le M z, \; x \ge 0$$
Condicional Se-Então $$\text{Se } z = 1 \implies a^T x \le b$$ $$a^T x \le b + M(1 - z)$$
Disjunção (Um ou Outro) $$(a_1^T x \le b_1) \;\lor\; (a_2^T x \le b_2)$$ $$a_1^T x \le b_1 + M z \quad \text{e} \quad a_2^T x \le b_2 + M(1 - z)$$
Lógica E (AND: $z = y_1 \land y_2$) $$z = 1 \iff y_1 = 1 \text{ e } y_2 = 1$$ $$z \le y_1, \quad z \le y_2, \quad z \ge y_1 + y_2 - 1$$
Lógica OU (OR: $z = y_1 \lor y_2$) $$z = 1 \iff y_1 = 1 \text{ ou } y_2 = 1$$ $$z \ge y_1, \quad z \ge y_2, \quad z \le y_1 + y_2$$

2. O Problema do Caixeiro Viajante (TSP)

Minimizar $\sum c_{ij} x_{ij}$ sujeito a $\sum_j x_{ij} = 1$ (grau de saída) e $\sum_i x_{ij} = 1$ (grau de entrada). Para impedir que a solução se decomponha em múltiplos subciclos desconectados, existem duas abordagens consagradas:

  • Formulação MTZ (Miller-Tucker-Zemlin): Adiciona variáveis de potencial escalar $u_i \in \mathbb{R}$ ($i=2,\dots,n$): $$u_i - u_j + n x_{ij} \le n - 1, \quad \forall 2 \le i \ne j \le n$$ Vantagem: Apenas $O(n^2)$ restrições (tamanho polinomial compacto).
  • Formulação DFJ (Dantzig-Fulkerson-Johnson): Cortes de eliminação de subciclo para todo subconjunto próprio não vazio $S \subset V$: $$\sum_{i \in S, j \in S} x_{ij} \le |S| - 1$$ Vantagem: Relaxação linear muito mais justa (bound dual superior), resolvida via geração dinâmica de planos de corte (Branch & Cut).

3. Algoritmo de Branch and Bound (B&B)

📌 As Três Regras de Poda de Nós na Árvore
  1. Poda por Inviabilidade: O relaxamento LP do nó filho não possui nenhuma solução factível ($\mathcal{P}_{\text{filho}} = \emptyset$).
  2. Poda por Limitante (Bound): O limitante inferior do relaxamento $z_{\text{relax}} \ge z_{\text{incumbente}}$ (o melhor inteiro já conhecido é superior ao potencial desse ramo).
  3. Poda por Integralidade: O relaxamento LP atinge uma solução onde todas as variáveis binárias/inteiras assumem valores estritamente inteiros ($x_j \in \mathbb{Z}$). Atualiza a solução incumbente se melhorar o custo!

4. Algoritmos de Otimização Não Linear Contínua (NLP)

Algoritmo Equação de Atualização Taxa de Convergência Custo por Iteração
Gradiente Descendente $$x_{k+1} = x_k - \alpha_k \nabla f(x_k)$$ Linear (lenta em vales estreitos) $O(n)$ (avaliação de derivadas de 1ª ordem)
Método de Newton $$x_{k+1} = x_k - [\nabla^2 f(x_k)]^{-1} \nabla f(x_k)$$ Quadrática (super rápida perto do ótimo) $O(n^3)$ (cálculo e inversão da Hessiana)
Quasi-Newton (BFGS) $$x_{k+1} = x_k - \alpha_k H_k \nabla f(x_k)$$ Superlinear $O(n^2)$ (aproximação cumulativa de $H = [\nabla^2 f]^{-1}$)
Busca Linear (Armijo) $$f(x_k + \alpha d_k) \le f(x_k) + c_1 \alpha \nabla f(x_k)^T d_k$$ Garante decrescimento suficiente Algumas avaliações de função por passo
