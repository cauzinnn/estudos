1. Álgebra das Formas Quadráticas

Uma forma quadrática pura em $n$ variáveis é expressa como $f(x) = x^T Q x$. Sem perda de generalidade, a matriz $Q$ pode ser sempre assumida simétrica ($Q = Q^T$):

$$x^T R x = x^T \left( \frac{R + R^T}{2} \right) x = x^T Q x$$
📌 Teorema Espectral para Matrizes Reais Simétricas

Toda matriz simétrica $Q = Q^T \in \mathbb{R}^{n \times n}$ admite uma decomposição ortogonal $Q = U \Lambda U^T$, onde: $$U^T U = I \quad \text{e} \quad \Lambda = \text{diag}(\lambda_1, \dots, \lambda_n)$$ As colunas $u_i$ de $U$ são autovetores mutuamente ortogonais de comprimento unitário, e $\lambda_i \in \mathbb{R}$ são os autovalores correspondentes.

2. Classificação de Curvatura e Geometria dos Elipsoides

Para uma matriz simétrica $Q$, o sinal da forma quadrática define sua convexidade:

  • Positiva Definida ($Q \succ 0$): Todos os $\lambda_i > 0$. A função é estritamente convexa com mínimo único na origem.
  • Positiva Semidefinida ($Q \succeq 0$): Todos os $\lambda_i \ge 0$. Convexa (pode ter vale plano se algum $\lambda_i = 0$).
  • Indefinida: Possui autovalores positivos e negativos. Forma um ponto de sela (não convexa).

Para $Q \succ 0$, a região $\{x \in \mathbb{R}^n \mid x^T Q x \le 1\}$ é um elipsoide. As direções dos eixos principais são os autovetores $u_i$, e o comprimento de cada semi-eixo é:

$$r_i = \frac{1}{\sqrt{\lambda_i}}$$
