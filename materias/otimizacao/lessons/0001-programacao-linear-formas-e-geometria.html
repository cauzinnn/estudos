1. Geometria da Otimização: Hiperplanos, Semiespaços e Poliedros

Um modelo de Programação Linear (PL) opera sobre conjuntos definidos por equações e inequações afins:

  • Hiperplano: $\{x \in \mathbb{R}^n \mid a^T x = b\}$. O vetor $a$ é o gradiente normal perpendicular à superfície; $b$ define o deslocamento da origem.
  • Semiespaço (Halfspace): $\{x \in \mathbb{R}^n \mid a^T x \le b\}$. Região convexa fechada de um dos lados do hiperplano delimitador.
  • Poliedro: Interseção finita de semiespaços $\{x \in \mathbb{R}^n \mid A x \le b\}$. Se for limitado, chama-se Politopo.

Uma combinação $w = \alpha x + (1-\alpha)y$ é afim para qualquer $\alpha \in \mathbb{R}$ (traça a reta inteira que passa por $x$ e $y$). É uma combinação convexa se e somente se $0 \le \alpha \le 1$ (o segmento fechado entre eles).

2. Os Três Regimes de Solução de um LP

Todo problema de Programação Linear cai obrigatoriamente em exatamente um destes três estados mutuamente exclusivos:

  1. Inviável (Infeasible): Não existe nenhum vetor $x$ que satisfaça simultaneamente todas as restrições ($\mathcal{P} = \emptyset$).
  2. Ilimitado (Unbounded): Existe uma direção factível $d$ ao longo da qual a função objetivo cresce indefinidamente ($c^T d > 0$ com $A d \le 0$), logo $\sup c^Tx = +\infty$.
  3. Solúvel (Solvable com Ótimo Finito): O conjunto factível é não vazio e limitado na direção do gradiente.
📌 Teorema Fundamental da Programação Linear

Se um problema de programação linear possui solução viável ótima finita, então pelo menos um vértice (ponto extremo / solução básica factível) é ótimo. Se múltiplos vértices forem ótimos, toda a face ou aresta poligonal formada pela combinação convexa desses vértices também será ótima.

3. Álgebra de Transformação para a Forma Canônica / Padrão

Para aplicar algoritmos como o Simplex, qualquer formulação geral de PL é convertida por regras de equivalência exatas:

  • Inversão de Objetivo: $\min c^T x \Longleftrightarrow \max (-c)^T x$. O valor ótimo final inverte o sinal: $\min = -(\max)$.
  • Sentido de Desigualdade: $a_i^T x \ge b_i \Longleftrightarrow -a_i^T x \le -b_i$.
  • Igualdade Afim: $a_i^T x = b_i \Longleftrightarrow (a_i^T x \le b_i) \land (-a_i^T x \le -b_i)$.
  • Variável Livre ($x_j \in \mathbb{R}$): Substitui-se $x_j = u_j - v_j$, com $u_j \ge 0$ e $v_j \ge 0$. Em qualquer base ótima, pelo menos uma das duas será nula.
