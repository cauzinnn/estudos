1. Modelagem de Cláusulas Se-Então (If-Then)

Frequentemente uma restrição física só é exigida quando uma condição lógica preliminar é satisfeita:

$$\text{Se } z = 1 \implies a^T x \le b$$

Para linearizar essa condicional, utilizamos o limitante superior Big-M ($M \ge \sup (a^Tx - b)$):

$$a^T x \le b + M(1 - z)$$
  • Se $z = 1 \implies a^T x \le b + 0 = b$ (a restrição física torna-se ativa e obrigatória).
  • Se $z = 0 \implies a^T x \le b + M$ (a restrição torna-se frouxa e inofensiva, redundante).

Para a condicional oposta ($\text{Se } a^T x \le b \implies z = 1$), aplica-se a equivalência contrapositiva ($\text{Se } z = 0 \implies a^T x > b \iff a^T x \ge b + \epsilon$).

2. Linearização das Portas Lógicas Fundamentais

Operação Lógica Tabela Verdade Sistema de Inequações Lineares Obrigatórias
AND ($z = y_1 \land y_2$) 1 apenas se $y_1=1$ e $y_2=1$ $$z \le y_1, \quad z \le y_2, \quad z \ge y_1 + y_2 - 1$$
OR ($z = y_1 \lor y_2$) 1 se pelo menos uma for 1 $$z \ge y_1, \quad z \ge y_2, \quad z \le y_1 + y_2$$
Implicação ($y_1 \implies y_2$) Se $y_1=1$, obriga $y_2=1$ $$y_1 \le y_2 \iff y_1 - y_2 \le 0$$

Exercício 1: Modelagem de Implicação Lógica

Em um processo industrial, se o reator químico 1 for ligado ($y_1 = 1$), o sistema de resfriamento de emergência 2 deve ser obrigatoriamente ligado ($y_2 = 1$). Se o reator 1 estiver desligado ($y_1 = 0$), o resfriamento pode estar ligado ou desligado.

Qual inequação linear única modela com exatidão essa regra de segurança para $y_1, y_2 \in \{0, 1\}$?
