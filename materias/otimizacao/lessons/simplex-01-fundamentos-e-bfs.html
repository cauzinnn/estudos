1. O Conceito Fundamental de Base em Programação Linear

Na forma padrão com $m$ equações e $n$ variáveis não negativas ($A x = b, x \ge 0$, com $m < n$ e $\text{posto}(A) = m$):

  • Escolhemos $m$ colunas linearmente independentes de $A$ para formar a matriz básica quadrada $B \in \mathbb{R}^{m \times m}$.
  • As $n - m$ colunas restantes formam a matriz não básica $N \in \mathbb{R}^{m \times (n-m)}$.
  • Fixamos todas as variáveis não básicas em zero: $x_N = \mathbf{0}$.

O sistema linear reduz-se a $B x_B + N(\mathbf{0}) = b \implies B x_B = b$. Como $B$ é invertível:

$$x_B = B^{-1} b$$
📌 Classificação Rigorosa de Soluções Básicas
  • Solução Básica Factível (BFS - Basic Feasible Solution): Se todas as variáveis básicas forem não negativas ($x_B \ge 0$). Toda BFS corresponde a um vértice (ponto extremo) do poliedro!
  • Solução Básica Inviável: Se pelo menos uma componente básica for estritamente negativa ($x_{Bi} < 0$). É um ponto de interseção geométrica que fica fora do poliedro factível.
  • Solução Degenerada: Uma BFS onde pelo menos uma variável básica é nula ($x_{Bi} = 0$).

2. O Número Máximo de Vértices e a Finitude do Simplex

Quantas soluções básicas distintas um problema de PL pode ter no máximo?

Como uma base consiste na escolha de $m$ colunas dentre as $n$ colunas totais de $A$, o número máximo de bases é o coeficiente binomial:

$$\binom{n}{m} = \frac{n!}{m! \, (n - m)!}$$

Embora $\binom{n}{m}$ seja um número finito (o que garante que o Simplex nunca visite infinitos vértices), esse valor cresce de forma combinatória astronômica para problemas de médio porte (ex: para $m = 20, n = 50$, temos mais de $4.7 \times 10^{13}$ bases!). É por isso que uma busca cega exaustiva é inviável, e o Simplex precisa da bússola inteligente dos custos reduzidos para navegar apenas pelas arestas que melhoram o lucro.
