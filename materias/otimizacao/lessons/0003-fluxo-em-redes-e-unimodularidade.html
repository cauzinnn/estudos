1. Modelo Geral de Fluxo de Custo Mínimo (Min-Cost Flow)

Uma rede é um grafo direcionado $G = (V, E)$ onde cada arco $e = (i, j) \in E$ conduz um fluxo $x_{ij} \ge 0$ com custo unitário $c_{ij}$ e capacidade máxima $u_{ij}$.

Cada nó $i \in V$ possui um balanço de suprimento/demanda $b_i$:

  • Nó de Oferta / Fonte: $b_i > 0$ (injeta fluxo na rede).
  • Nó de Demanda / Sumidouro: $b_i < 0$ (consome fluxo da rede).
  • Nó de Transbordo (Intermediário): $b_i = 0$ (todo fluxo que entra deve sair).

A lei de conservação em cada nó $i$ impõe que a soma do fluxo que sai menos o fluxo que entra deve ser igual a $b_i$:

$$\sum_{j : (i,j) \in E} x_{ij} - \sum_{k : (k,i) \in E} x_{ki} = b_i, \quad \forall i \in V$$

2. A Matriz de Incidência Nó-Arco ($A x = b$)

Na forma matricial compacta $Ax = b$, a matriz de incidência $A \in \mathbb{R}^{|V| \times |E|}$ possui uma linha para cada nó e uma coluna para cada arco direcionado $e = (i, j)$:

  • $A_{i, e} = +1$ (o arco sai do nó $i$ - cauda).
  • $A_{j, e} = -1$ (o arco entra no nó $j$ - cabeça).
  • $A_{k, e} = 0$ para qualquer outro nó não incidente.
📌 Teorema do Equilíbrio Global de Redes

Como cada coluna de $A$ possui exatamente um $+1$ e um $-1$, a soma de todas as linhas de $A$ é identicamente zero: $\mathbf{1}^T A = \mathbf{0}^T$. Logo, para que o sistema $Ax = b$ seja viável, é estritamente obrigatório que a soma das ofertas seja igual à soma das demandas: $$\mathbf{1}^T b = \sum_{i \in V} b_i = 0$$

3. Total Unimodularidade (TU) e Soluções Inteiras

Uma matriz $A$ é Totalmente Unimodular (TU) se o determinante de toda submatriz quadrada pertence a $\{-1, 0, 1\}$.

📌 Teorema de Hoffman-Kruskal

Se a matriz de restrições $A$ for Totalmente Unimodular e o vetor $b$ for inteiro, então todos os vértices do poliedro $\{x \mid Ax = b, x \ge 0\}$ são inteiros!

Toda matriz de incidência nó-arco de fluxo em redes é comprovadamente TU. Logo, problemas como Designação e Caminho Mínimo podem ser resolvidos como LPs contínuos, fornecendo resultados estritamente inteiros sem qualquer necessidade de Branch & Bound.
